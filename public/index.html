garmin-mcp token extractor

Self-hosted tool. Not affiliated with, or endorsed by, Garmin.

Prefer the local command. Running npm run auth on your own machine produces the same token and never sends your password anywhere. Use this page only when you cannot run Node locally. Your password passes through this server in memory to reach Garmin; it is never stored, written to disk, or logged.

Paste the value into your MCP client's env block, or save tokens.json to ~/.garmin-mcp/tokens.json. Treat both as passwords — they grant full access to the account until the refresh token expires.
